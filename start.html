まず動かしてみる

読む前に、動かす。5分で終わります

この章の3行まとめ
  • この18本は、ブラウザだけで動きます。インストールは何も要りません。
  • Babylon.js Playground という公式サイトに、ファイルの中身をまるごと貼って実行するだけです。
  • 先に動かして、数字をひとつ壊してみる。説明を読むのはそのあとのほうが、ずっと早く分かります。

このプロジェクトの .js ファイルは、ふつうの Web ページに読み込んで使うものではありません。 Babylon.js Playground（バビロン・ジェイエス・プレイグラウンド）という、 ブラウザの中で3Dのプログラムを書いて即座に実行できる公式サイトのための形になっています。

  1. Playground を開く

    playground.babylonjs.com をブラウザで開きます。左が入力欄、右が3Dの画面です。 パソコンのほうがやりやすいですが、スマホでも動きます。

  2. もとから入っているコードを全部消す

    左側をクリックして、Ctrl+A（Mac は ⌘+A）で全選択 → Delete。 まっさらにしてから貼るのがコツです。混ざると動きません。

  3. ニンジン.js の中身を全部コピーして貼る

    最初の1本は ニンジン.js がおすすめです。18本のなかでいちばん構造が素直で、 「円錐に溝を彫る」だけでできています。ファイルをテキストエディタで開き、 全部コピーして、Playground の左側に貼り付けます。

  4. 実行する

    上の Run ボタン（または Alt+Enter）。 数秒待つと、ざるに人参が盛られていきます。 右下にスライダーが出るので、動かしてみてください。

    うまくいかないとき

    真っ黒のまま／エラーが出る — 貼り付けたときに古いコードが残っていないか確認してください。 また、物理エンジン（Havok）の読み込みに数秒かかります。少し待ってみてください。

    動きがカクカクする — 3Dの計算をパソコンが全部やっています。 ブラウザの他のタブを閉じると軽くなります。

  5. 数字をひとつ、わざと壊す

    ファイルの上のほうにある PRESETS の中から radius: 2.05 を探して、 radius: 6.0 に書き換えて Run。ぶっとい人参が出てきます。 どの数字が何に効くかは、壊すといちばん早く分かります。 壊しても保存されないので、いくらでも試して大丈夫です。

18本のうち、どれから読むか

  • ニンジン.js — いちばん素直。円錐 + 溝。まずこれ。
  • キュウリ.js — 稜（縦のすじ）とイボ。テクスチャの作りが分かりやすい。
  • トマト.js — 肩が折り返す形。ここから少し難しくなります。
  • シイタケ.js / トウモロコシ.js — 構造が複雑。慣れてから。
プログラミングが初めてでも大丈夫。 この教材で使う数学は、三角関数（sin・cos）と座標と比例がほとんどです。 高校1年までの内容で、9割は追えます。分からない言葉が出てきたら 用語集を見てください。

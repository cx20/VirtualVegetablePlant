17Exponent

平たさと角を、指数ひとつで決める

superellipse — 超楕円

この章の3行まとめ
  • 円の式 x² + y² = 1 の「2」を大きくすると、形は平たく、角ばっていきます。これが超楕円です。
  • ミカンは横顔に、柿は横顔と上から見た断面の両方に、この式を使っています。
  • 点を何十個も並べた表より、数字が1つだけの式のほうが、その果物らしさを外しにくいことがあります。

ミカン.js の冒頭に、こんな記録が残っています。「リンゴの形に見える」。 それまでのミカンは、04章と同じように横顔を26個の点の表（MERIDIAN）で描いていました。 高さを縮めて扁平にしても、どうしてもリンゴにしか見えなかったのです。

原因は、点の並びそのものにありました。コメントによると、その表は 「天面の中央が深くくぼみ、そのまわりの肩が盛り上がる」 「いちばん太いところが中央より上にあり、下へすぼまる」形になっていました。 これはリンゴの特徴そのものです。点の並びに染みついているので、全体を縦に潰しても消えません。 実物の温州みかんは、天面も底面も広く平らで、いちばん太いのはほぼ真ん中です。

円の式の「2」を変える

半径1の円は x² + y² = 1 と書けます。この「2」を、好きな数 n に変えてみます。

|x|n + |y|n = 1

これを超楕円といいます。n = 2 ならふつうの円（縦横の長さを変えれば楕円）。 n を大きくすると、上下左右が平らになって角の丸い四角へ近づきます。 n を 2 より小さくすると逆に痩せて、n = 1 でひし形になります。 数字を1つ変えるだけで、「丸」と「四角」のあいだを好きな位置で止められるわけです。

プログラムでは、この式を角度 θ で表した形（媒介変数表示）で使います。

なぜ「2 / n 乗」なのかは、式に代入すると分かります。 rn = (sin θ)2、yn = (cos θ)2 になるので、 足すと sin²θ + cos²θ = 1。ちゃんと超楕円の上に乗っています。 高校1年の三角比で確かめられる計算です。

もうひとつの工夫は、上半分と下半分で n を変えていることです。 実物の果物は上下対称ではありません。サンプルに入っている指数を並べると、こうなります。

サンプル天面の n底面の n見た目
スイカ（大玉）2.162.10ほぼ球。わずかに張っている
三ヶ日みかん2.602.25天面が広く平ら。底はやや丸い
富有柿2.702.30肩が張って、やや角張る
次郎柿3.202.60上も下も平らで、四角い

スイカ.js も、実は同じ式で作っています（04章ではそこまで触れませんでした）。 2.1 と 3.2 の差はわずかに見えますが、並べると球・ミカン・柿ときちんと別物になります。

実験 — 指数で形を変える

「表の横顔」と「三ヶ日みかん」を切り替えて比べてください。高さ ÷ 直径は同じ 0.81 です。 下の図の点線は n = 2（ふつうの楕円と円）です。

柿は、上から見ても超楕円

柿を真上から見ると、丸ではなく角の丸い四角をしています。がく片が4枚で、 そのあいだに浅い縦の溝が4本走っているからです。 柿.js は、横顔に使ったのと同じ式を、今度は水平の断面に使っています。

ここには細かい工夫が2つあります。

  • 上下の端に近づくほど n を 2（円）へ戻す。四角いのは胴だけで、へたのまわりと花落ちのまわりは丸い。 端まで四角のまま絞ると、へたの下から角が4本突き出したような形になります。
  • 平均の半径をそろえる。n を上げると角が外へ張り出すので、同じ大きさのつもりでも一回り大きく見えます。 角の向きの半径（1）と、辺の真ん中の向きの半径（21/2 − 1/n）の平均で割って、 「四角さ」を変えても大きさが変わらないようにしています。

溝は、角と角のちょうど中間に山形の関数（ガウス関数）を4つ置いて、そのぶん半径を削っています。 溝の深さは1本ずつ乱数で 0.55〜1.30 倍に揺らします。4本とも同じ深さだと、型で抜いたように見えるからです。 がく片4枚の向きもこの角にそろえます（そろえないと、溝の筋とがく片がずれます）。

つまずきポイント

表と式は、どちらが上というものではありません。 式は数字が少ないので、その果物らしさを外しにくい。そのかわり、式に無い形は作れません。 トマトの肩が内側へ折り返す形（04章）は、超楕円では書けません。 実際、ミカン.js でも超楕円を使っているのは三ヶ日みかんだけで、温州みかん・青みかん・ ポンカン・デコポンの4品種は今も表（superN: 0）のままです。 デコポンの「でこ」は、表に足し算して作っています。 どちらを選ぶかは、実物の写真を横に並べて決めてください。

同じファイルの、ほかの見どころ

ミカン.js と 柿.js には、超楕円のほかにも、ほかの章とつながる工夫が入っています。

  • 油胞（ミカンの皮の粒）は、格子に並べてから少しずらす（ミカン.js の oilGlands()）。 完全にでたらめに置くと、粒が固まったところとすき間ができます。 極に近い行は粒の数を sin(πv) 倍に減らします。極ではテクスチャの横方向が縮むからです（→ 06章）。
  • 粒は色ではなく艶で見せる。はじめは油胞を濃い色の点で塗っていたので、 「水玉模様を印刷したように見える」という記録が残っています。 実物の粒は色の差がほとんどなく、ハイライトのなかで光り方が変わって見えるだけ。 色の濃さ glandInk を 0.42 から 0.12 へ下げ、そのぶんを粗さの差に回しました（→ 07章）。
  • 竹ざるの編み目は、真上から平らに貼る（柿.js の ZaruLab.weave()）。 網代（あじろ）編みのひごは、器の形に関係なく平行に走ります。 回転体と同じように極座標でテクスチャを貼ると、ひごが中心へ放射状に集まって「蜘蛛の巣」になります（→ 06章）。
  • 当たり判定の底を、1.8mm だけ削いで平らにする（柿.js の hullShape()）。 柿の底は丸いので、凸包の底がほぼ同じ平面の小さな面の集まりになり、 ざるに載ったあと5秒以上揺れ続けていました。見た目には出ない量だけ削ると止まります（→ 08章）。
やってみよう
  1. 天面と底面の n を両方 2.00 にして、ただの扁平な楕円体に戻す。何に見えるか。
  2. 次郎柿で、断面の四角さを 2.00（丸）に戻す。それでも柿に見えるか。
  3. 「表の横顔」と「三ヶ日みかん」を切り替えて見比べ、表のほうがリンゴっぽく見える理由を言葉にする。
  4. 柿.js の次郎柿の squareN を 4.0 にして Playground で実行する。どこまで四角くすると柿に見えなくなるか。

最初の1周で引っかかりやすいものだけ

語意味
メッシュ頂点と三角形でできた立体そのもの。
頂点 / positions点の座標。x,y,z の3つずつ一列に並べる。
indicesどの点とどの点で三角形を作るかの番号表。
法線 / normal面がどちらを向いているかの矢印。明るさを決める。
UV立体の表面と画像の座標の対応。u=横、v=縦。
巻き順三角形の頂点を並べる向き。表裏を決める。
掃引 / sweep断面を並べてつなぎ、立体にすること。
プロファイル形の横顔。半径や高さの表。
ノイズなめらかにつながる乱数。自然な模様のもと。
fBm / オクターブ細かさを半分ずつにしたノイズを重ねる手法。
アルベド影も光沢もない、素の色。
ORM陰り・粗さ・金属度を R,G,B に詰めた1枚の画像。
PBR現実の光の法則に沿った質感の表し方。
SSS / subSurface光が中に入って散る現象。薄い部分が透ける。
クリアコート表面にかかった透明な膜。ワックスの艶。
シード乱数の出発点になる整数。同じなら同じ結果。
HavokBabylon.js が使う物理エンジンの名前。
Playgroundブラウザ上で Babylon.js のコードを試せる公式サイト。
再帰関数が自分自身を呼ぶこと。枝分かれした形はこれで作る（12章）。
自己相似どこを拡大しても同じ形が出てくる性質。ロマネスコがその代表。
葉序 / phyllotaxis植物が葉や種をつける並び方。137.5°ずつ回すのが基本（13章）。
黄金角360° ÷ φ² ≒ 137.5°。もっとも重なりにくい角度。
斜列 / parastichy葉序の並びに目で見える螺旋。本数がフィボナッチ数になる。
フィボナッチ格子球や円板に点を等密度でばらまく方法。極でも混み合わない。
散房花序枝の長さを変えて花を同じ高さに揃える咲き方。ブロッコリーの頭はこれ。
包絡面 / envelope房の先端がそろって作る、頭全体のなめらかな面。
頂点カラー頂点ひとつずつが持つ色。テクスチャを貼らずに塗る（14章）。
遮蔽 / AOすみっこに光が届かない暗さ。ここでは頂点の色へ焼き込んでいる。
焼き込む / bake実行のたびに計算せず、あらかじめ結果を色や画像へ書き込んでおくこと。
シェル法 / shell fur少し大きくしたコピーを重ねて毛を出す手法（15章）。
被覆率親の面が子でどれだけ埋まっているかの比。1を切ると下地が見える。
超楕円 / superellipse|x|n + |y|n = 1 で表される形。n = 2 で円、大きいほど角の丸い四角に近づく（17章）。
媒介変数表示x と y を、別の1つの数（角度 θ など）で表す書き方。曲線の上を順に点を打てる。
油胞ミカンの皮の表面に並ぶ、油をためた小さな粒。
網代 / あじろ竹のひごを数本越え・1本潜りで編む編み方。ひごは器の形に関係なく平行に走る。

次にやること

  • 01まず動かすBabylon.js Playground に ニンジン.js をそのまま貼って実行する。読む前に動かす。
  • 02数値をひとつ壊すCONFIG の radius を10倍にしてみる。どこが効いているか、壊すといちばん早くわかる。
  • 03色を変えるプリセットの色（sRGB 0〜1の3つ組）を書き換えて、白いにんじんを作ってみる。
  • 04プロファイルを書き換える半径の式をいじって、ありえない野菜を作る。ここまでできれば構造は理解できている。
  • 05新しい野菜を1本書くニンジン.js を複製して大根にする。円錐で白くて、輪紋のかわりに横筋。

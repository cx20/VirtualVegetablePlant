# やさいのつくりかた（VirtualVegetablePlant）

コードで野菜を育てる技術ノート — [Babylon.js](https://www.babylonjs.com/) による手続き的モデリングの学習サイト。

**→ [https://cx20.github.io/VirtualVegetablePlant/](https://cx20.github.io/VirtualVegetablePlant/)**

3Dモデルファイルも写真も **1枚も読み込みません**。点の座標を計算で並べ、模様をその場で描き、
光り方を数値で決める。そうやって作った野菜・果物・きのこ 25 本のサンプルと、
それを中学生・高校生向けにほどいた全 17 章の解説で構成しています。

必要な数学は sin・cos、座標、比例、それに少しのベクトル（内積・外積）。高校1年までの内容でだいたい追えます。

---

## まず動かす

サンプルは [Babylon.js Playground](https://playground.babylonjs.com/) 用の形になっています。
インストールは何も要りません。

1. [playground.babylonjs.com](https://playground.babylonjs.com/) を開く
2. 左側のコードを全部消す（`Ctrl`+`A` → `Delete`）
3. [samples/ニンジン.js](samples/ニンジン.js) の中身を全部コピーして貼る
4. **Run**（`Alt`+`Enter`）

数秒待つと、ざるに人参が盛られていきます。詳しくは [00 まず動かしてみる](https://cx20.github.io/VirtualVegetablePlant/start.html) を参照してください。

サイト内の[図鑑](https://cx20.github.io/VirtualVegetablePlant/zukan.html)からは、Playground へ行かずに
その場でサンプルを実行することもできます。

## ローカルで開く

`file://` でも一応動きますが、ソースビューアは `assets/src/` の複製（ビルド生成物）に頼る形になります。
HTTP で開くのが確実です。

```sh
git clone https://github.com/cx20/VirtualVegetablePlant.git
cd VirtualVegetablePlant
node tools/build.js          # assets/src/ を生成（.gitignore 済みのため clone 直後は空）
npx serve .                  # 任意の静的サーバでよい
```

## サンプル 25 本

`samples/` 以下。同じ枠組みで書かれていますが、担当する「難所」が 1 本ずつ違います。

| ファイル | そこでしか出てこない技術 |
| --- | --- |
| [ニンジン.js](samples/ニンジン.js) | 円錐＋輪紋＋側根痕。構造がいちばん素直なので、最初に読むならこれ |

| [トマト.js](samples/トマト.js) | 肩のくぼみと、萼片を1枚ずつ立体で作るがく。(r, y) の2列テーブルが要る形の代表 |
| [ナス.js](samples/ナス.js) | クリアコートの加減がすべて。強すぎると黒ガラス、弱いとゴム |
| [ピーマン.js](samples/ピーマン.js) | 縦に3本の深い溝と、そのあいだの丸い「片」。ヘタは星形のがく |
| [オクラ.js](samples/オクラ.js) | 丸めた正五角形の断面と産毛。sheen（布のような照り）を使う数少ない例 |

| [ジャガイモ.js](samples/ジャガイモ.js) | 極でUVが潰れる問題への対処が全編にわたる。3Dノイズを使う理由 |
| [サツマイモ.js](samples/サツマイモ.js) | 紡錘形と根跡の縦の列。艶消しの表面を粗さの分布だけで作る |
| [トウモロコシ.js](samples/トウモロコシ.js) | 粒を実体のメッシュとして作り、芯に植えて結合する |
| [シイタケ.js](samples/シイタケ.js) | ひだ（ラメラ）を実体で立てる。裏返っても嘘にならない作り方 |
| [エリンギ.js](samples/エリンギ.js) | 主役は柄。柄が上へ広がってそのまま傘になる、垂生のひだ |
| [玉ねぎ.js](samples/玉ねぎ.js) | 異方性・シーン・透過の3つで乾いた薄紙を出す。PBRの合わせ技 |
| [スイカ.js](samples/スイカ.js) | 縞が極で1点に集まるのは、u を周方向にとった結果。UVの意味 |
| [メロン.js](samples/メロン.js) | 網目に視差マッピング。法線マップのアルファに高さを入れる小技つき |
| [リンゴ.js](samples/リンゴ.js) | 5裂の断面と2つのくぼみ。クリアコートが掛け算で効く落とし穴の記録 |
| [ブドウ.js](samples/ブドウ.js) | 粒を数十個配置して重なりを解消する反復計算。房の作り方 |
| [バナナ.js](samples/バナナ.js) | 断面が5稜の多角形。回転体ではなく、曲がった軸に沿った掃引 |
| [サクランボ.js](samples/サクランボ.js) | 球ではなくハート形。黄色い地色に赤が回り込み、境目に斑点が飛ぶ |
| [枝豆.js](samples/枝豆.js) | 豆の膨らみを「なめらかな max」で合成。産毛はシェルを重ねて生やす |
| [ブロッコリー.js](samples/ブロッコリー.js) | テクスチャを1枚も使わない。房を再帰で生やし、谷の暗さを頂点カラーに焼く |
| [カリフラワー.js](samples/カリフラワー.js) | ブロッコリーと同じ骨格。数値を4か所変えるだけで別の野菜になる |
| [ロマネスコ.js](samples/ロマネスコ.js) | 黄金角137.5°と等比数列だけで自己相似の螺旋が生まれる |
| [ミカン.js](samples/ミカン.js) | 26点の横顔をやめて超楕円に。油胞は色ではなく艶の差で見せる。5品種入り |
| [柿.js](samples/柿.js) | 横顔も、上から見た断面も超楕円。角の丸い四角と4本の溝。網代のざるは真上から貼る |

どのファイルも先頭に「構成」というコメントがあり、`0. CONFIG` → `1. Rng` → `2. Noise` →
`3. Mesh utils` → `4. Profile / Fields` → `5. TextureLab` → `6. 本体` → `7. Basket` →
`8. Scene / 物理` → `9. GUI` の順に並んでいます（ブロッコリー・カリフラワー・ロマネスコの
3本だけはこの並びに収まりません。→ 第II部）。

コメント中の **【対策】** は「一度失敗して直した記録」です。なぜその数値なのか、
なぜその順番なのかは、たいていそこに書いてあります。

## 章立て

### 第I部 — 1個の野菜をつくる（00〜11）

1本の .js ファイルを、上から順にほどいていく構成です。

| | 章 | 内容 |
| --- | --- | --- |
| 00 | まず動かしてみる | インストールなし。ブラウザだけで25本を動かす手順 |
| 01 | 手続き生成 | モデルを読み込まずに、実行した瞬間に座標を計算で作る。その利点と代償 |
| 02 | 乱数 | `Math.random()` を使わない理由。種を渡すと毎回同じ結果になる乱数を書く |
| 03 | ノイズ | となり合う値がなめらかにつながる乱数。重ねると自然物の模様になる（fBm） |
| 04 | かたち | 横顔の折れ線を1本描いて軸のまわりに回す。**この教材の背骨** |
| 05 | 面と法線 | 3Dモデルの正体は座標の配列と三角形の番号表。裏返ると立体が消える理由 |
| 06 | テクスチャ | UVで立体と画像を対応させ、模様を1ピクセルずつ計算で描く |
| 07 | PBR | 「濡れている」「粉をふいている」を数値で書く。粗さ・クリアコート・透け |
| 08 | 物理 | ざるへの盛り付けは手で置かない。重力と摩擦を与えて Havok に任せる |
| 09 | 部品 | 粒・ひだ・房。部品を1個作って何百個並べ、合体させる |
| 10 | 曲がり | 先に軸を決め、断面を軸に垂直に置いていく（掃引） |
| 11 | 光 | 同じ野菜でも光で別物になる。IBL・影・露出・トーンマッピング |

### 第II部 — 構造そのものをつくる（12〜17）

回転体でも掃引でも作れないブロッコリー・カリフラワー・ロマネスコが持ち込んだ 5 つの技術と、
ミカン・柿が持ち込んだ超楕円（17章）。層ではなく「作り方の種類」で立てた章です。

| | 章 | 内容 |
| --- | --- | --- |
| 12 | 再帰 | 同じ手順を小さくしてくり返すだけ。むずかしいのは止め方 |
| 13 | 螺旋（葉序） | 137.5°ずつ回して置くだけで、8本・13本・21本の螺旋が勝手に現れる |
| 14 | 頂点カラー | 枝分かれした形にUVは張れない。色も影も頂点ひとつずつに焼き込む |
| 15 | シェル | 産毛は法線マップでは出ない。少し大きい殻を重ねて輪郭に毛を立てる |
| 16 | 差分設計 | ブロッコリーとカリフラワーは同じプログラム。白くしただけでは似ない |
| 17 | 超楕円 | 円の式の「2」を大きくすると平たく角ばる。ミカンの横顔も柿の四角も指数ひとつ |

## ビルドとサムネイル収録

どちらも Node.js だけで動きます（追加の依存パッケージはありません）。

```sh
node tools/build.js
```

`assets/_index_original.bak.html` と `samples/*.js` を入力に、ルートの全 HTML ページと
`assets/src/*.src.js`（ソースビューア用の複製）を生成します。**HTML は毎回まるごと上書き**されます。

```sh
node tools/shoot.js            # 25本ぜんぶ撮り直す（10〜15分）
node tools/shoot.js ニンジン   # 名前で絞り込み（部分一致）
```

図鑑カードの写真を収録します。ヘッドレスの Chrome を DevTools プロトコルで操り、
サンプルを実際に実行して、物理が落ち着いたところで撮ります。GPU がなくても SwiftShader で描けます。
出力は `assets/thumbs/`（`*.jpg` / `index.json` / `thumbs.js`）で、これはリポジトリに含めて配ります。
撮り直しが要るのは**サンプルの見た目を変えたときだけ**です。

手書きで管理していて、上のスクリプトが触らないもの: `assets/site.css` / `assets/labs.js` /
`assets/havok-lab.js` / `assets/play.js`。
